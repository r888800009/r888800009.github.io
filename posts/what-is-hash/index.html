理解Hash

在我們談論雜湊(Hash)之前，我們先看看hash這個單字在英文究竟是什麼意思，比方說 hash brown 的中文為薯餅，其意義將馬鈴薯切碎之後將煎成褐色的薯餅。由馬鈴薯變成薯餅的這個行為，就像雜湊函數(Hash function)將資料加工成雜湊值一般。

可是hash function好多種，究竟要從哪個學起呢，這邊我們不從SHA-256、MD5談起，這樣實在太難理解了。

於是我們將f(x) = x % 2048寫成下面這個函數:

int hash(const char *str)
{
    int result = 0;
    while (*str != '\0') {
        result = (result + *str) % 2048;
        str++;
    }

    return result;
}

這時我們把字串"hash me"給帶進去，之後我們就得到662這個結果，他就是你的雜湊值

雜湊有什麼好處呢，雜湊可以利用本身的特性達到十分快速的效果，不過相對的也必須付出代價 碰撞
