關於 if else to asm

由於編譯的時候會把 if else 轉成 asm

If (cond)
  statement1;
else
  statement2;

可以轉換成下面的偽代碼

  cmp cond
  If (!cond)
    jmp false

  statement1
  
  jmp done
false:
  statement2
done:

看到上面這種方法，就在思考 decompiler 是不是可以拿 antlr 去實作啊?如果有辦法，反過來做以上思路，就可以達成反編譯的效果。

我們先把偽代碼改成以下形式，可能需要做 multiple-pass，我們一開始先做第一個 pass，如果遇到 jmp 先解析 xref，並且在該位置標上 xref_mark:，為了方便剖析 xref_mark: 可以重複。

  instr_cmp
  instr_jmp

  statement*
  
  instr_jmp
xref_mark:

  statement*
xref_mark:

但是實際下去研究時，我們會發現，雖然我們可以做 mark，但是得到的依然不是上面的語法。而這個問題要怎麼解決呢?
